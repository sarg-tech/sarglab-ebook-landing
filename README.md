# UNES — Landing Page Acadêmica

Releitura responsiva de um dos meus primeiros projetos de desenvolvimento web.

A proposta desta versão foi preservar a base do projeto original e modernizar a experiência visual, organização do código e comportamento em diferentes tamanhos de tela.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Melhorias desta versão

- layout responsivo para desktop, tablet e celular;
- menu mobile funcional e acessível;
- navegação por seções;
- caminhos relativos compatíveis com GitHub Pages;
- HTML mais semântico;
- remoção de JavaScript sem referência no DOM;
- identidade visual mais limpa e atual;
- conteúdo demonstrativo no lugar de textos `Lorem ipsum`.

> Projeto acadêmico demonstrativo. A instituição UNES apresentada nesta página é fictícia.
